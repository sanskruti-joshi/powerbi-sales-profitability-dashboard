# Dataset

## Financial Sample

The **Financial Sample** is Microsoft's example dataset for learning and demonstrating sales and financial analysis in Power BI.

| | |
|---|---|
| Dataset | Financial Sample |
| Provider | Microsoft |
| Official source | [Power BI sample datasets](https://learn.microsoft.com/en-us/power-bi/create-reports/sample-datasets) |
| Used in | [`Business_Performance_Analysis.pbix`](report/Business_Performance_Analysis.pbix) |

## What It Supports

The report uses the dataset to explore:

- Sales and profit
- Monthly sales and profit trends
- Product performance
- Segment profitability
- Units sold
- Revenue by country

## Availability and Setup

The source dataset is not included or redistributed in this repository.

1. Open the official [Power BI sample datasets](https://learn.microsoft.com/en-us/power-bi/create-reports/sample-datasets) page.
2. Download the Financial Sample workbook.
3. In Power BI Desktop, open [`Business_Performance_Analysis.pbix`](report/Business_Performance_Analysis.pbix).
4. Refresh the report or update the source path if prompted.

Use the data only in accordance with Microsoft's licensing and terms for the sample dataset.
